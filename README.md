# 深圳气象预警（ClassIsland 2 插件）

从深圳市气象台接口获取实时预警信号，在主界面横排显示。

- 数据接口：https://weather.121.com.cn/data_cache/szWeather/alarm/szAlarm.json
- 官方图标：https://weather.sz.gov.cn/alarmIcon/{icon}.png （icon 字段名，如 taifengchengse）
- 每 5 分钟自动刷新，网络失败保留上次数据
- 鼠标悬停任一条目显示该预警完整正文（满足气象台"完整传播"要求）

## 组件设置（点组件上的齿轮）

1. **显示模式（地区过滤之后生效）**
   - 所有预警
   - 最高级别预警（含并列，按颜色级别）
   - 最新一条预警（按发布时间）
   - 每种预警中级别最高的一条（按类型分组取最高级）
2. **显示元素**：预警图标 / 预警类型（台风）/ 预警级别（橙色）分别开关
3. **图标来源**：默认官方在线图标；勾"使用本地图标"后按 icon 字段名在指定文件夹自动匹配 *.png
4. **图标尺寸 / 圆角半径**：12–48 px 滑块；圆角 0–24 px（0 为方角）
5. **区域过滤**：空格分隔关键词，仅当 alarmArea 含任一关键词才显示；留空则全部
6. **无预警占位**（两项可独立开关）
   - 占位文字（默认"无预警"，可改）
   - 占位图片（本地图片路径，可浏览选择）

## 编译

1. 安装 .NET 8 SDK
2. `dotnet build -c Release`
3. 用生成的 `.cipx` 安装，或把 `bin/Release/net8.0/` 整个目录覆盖到插件目录

## 本地图标 / 占位图片放置

- 本地图标：插件目录/Icons/ 下按 icon 字段命名（如 taifengchengse.png）
- 占位图片：任意本地 png/jpg，在设置里"浏览"选即可
